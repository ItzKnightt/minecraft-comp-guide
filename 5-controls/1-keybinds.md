# Keybinds

Keybinds should make the actions you use most often the easiest to press,
and the actions you use together physically compatible. There's no single
correct layout — but there are wrong ones (unreachable, conflicting, or
changed every week).

## Principles

1. **Thumb buttons are premium real estate.** Anything you need mid-fight
   (drop item, hotbar swap, offhand toggle) belongs on a mouse side button.
2. **No finger does two critical things.** If your ring finger holds A to
   strafe left *and* has to press F for offhand, you lose strafing exactly
   when it matters most.
3. **Never rebind mid-grind.** Muscle memory needs consistent keys; changing
   binds resets weeks of feel.
4. **Test compatibility:** hold W+A and press each combat key — any combo
   that twists your hand will fail you in a real fight.

## Combat-critical binds to set deliberately

| Action | Typical choice | Notes |
|--------|---------------|-------|
| Sprint | Toggle-sprint mod, or a thumb key | Never hold W to sprint |
| Drop item | Mouse thumb button or Q | For drop-debuffs and clutter control |
| Offhand swap | Thumb button or F | Instant pot/shield swaps |
| Hotbar slots 1–9 | Number row, or 1–5 + thumb-shift schemes | Reach every slot without releasing WASD |
| Perspective swap | F5 variant on an easy key | For crystal/anchor play |
| Pick block | Middle click stays default | Sets the hotbar slot fast |

## Building the layout

1. Start with defaults; change only what hurts.
2. Play 2–3 sessions; the awkward keys will announce themselves.
3. Fix one bind at a time, then stop — endless fiddling is procrastination
   with extra steps.

## Consistency across modes

Keep the same movement and combat binds across PvP, speedrunning, and SMP
instances. Only change mode-specific binds (e.g. an F3-heavy speedrun bind)
where they don't collide.
